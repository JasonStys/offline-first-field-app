# Manual accessibility checklist

Record date, device, OS, assistive technology, version, and observations for every completed item.
Unchecked items are not failures; they are unexecuted manual evidence.

## Windows

- [ ] Narrator announces title, notes, save, sync, status, and list items meaningfully.
- [ ] Keyboard-only focus order follows visual order and remains visible.
- [ ] 200% text scaling does not clip actions or inspection content.
- [ ] High-contrast mode preserves control boundaries and status readability.

## Android

- [ ] TalkBack announces labels, roles, state, and save/sync outcomes.
- [ ] Switch Access reaches every interactive control without a trap.
- [ ] Largest font/display settings keep primary actions operable.
- [ ] Portrait and landscape layouts remain usable.

## Workflow

- [ ] Empty title validation is announced without relying on color.
- [ ] Offline save confirmation is announced.
- [ ] Timeout/offline retry state is announced and preserves the draft.
- [ ] Conflict count is announced without silently changing local text.
- [ ] Reduced-animation platform settings do not block information or actions.
