## 1.0.0 — 2026-09-18

### Added

- Android/Windows .NET MAUI offline inspection client.
- Transactional SQLite cache, outbox, migrations, conflict state, cursor, and crash recovery.
- Bounded attachment streaming with SHA-256 metadata.
- Idempotent optimistic-concurrency sync API and deterministic delta pulls.
- Field-aware three-way merge policy with explicit user-text conflicts.
- Deterministic demo, local performance budgets, comprehensive tests, and hosted verification.
